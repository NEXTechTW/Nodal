# Tutorial — your first Nodal map

1. **Open the editor.** `pnpm dev` → http://localhost:5173
2. **Load the example.** Click `Example` in the toolbar (fictional Lumen City).
3. **Add a station.** Press `A` (or the Add-station tool), click an empty area.
4. **Rename it.** Select the station, edit “Name (English)” in the right panel.
   Add “Name (繁體中文)” if your map needs it.
5. **Draw a line.** Create a line name in the left panel, press `C`, drag from
   one station to another. Lines sharing a track offset automatically.
6. **Arrange labels.** Right panel → “Arrange labels to avoid overlap”.
7. **Export.** `Export SVG` (vector), `PNG` (2× image), or `PDF` (print view).
8. **Save.** `Save` writes open JSON (`schemaVersion: 1`) you can version-control.

Shortcuts: `V` select · `A` add · `C` connect · `H` pan · `Delete` delete ·
`Esc` clear selection · `Space` + drag pan · scroll zooms to cursor.
